# Source verification ledger: biomedical AI and RAG

**Author:** Paul Skeffington · **Prepared with OpenAI** · **Checked:** 2026-10-14

This ledger records bibliographic identity checking against publisher pages,
professional scholarly indexes, or DOI landing pages. It is a **narrative
scoping review** rather than a systematic search; there is no PRISMA claim.
Every recorded DOI and its associated paper title, lead author, and publication
year were checked; original implementations, data and model weights were **not**
downloaded, run, audited or approved for redistribution. Verification URLs
are for citation identity only, **not** scientific replication or license clearance.

## Paper-reported implementation patterns and independent tests

| Publication | What the publication reports | What our independent code must test | Boundary |
| --- | --- | --- | --- |
| [Kuhn 2008](https://doi.org/10.18637/jss.v028.i05) | Describes caret's unified R modeling, preprocessing, resampling and tuning interfaces | Independent synthetic repeated-subject split, groupKFold CV, fold-local preprocessing and held-out confusion metrics | Reference for algorithms and code practices, not validation of any clinical model |
| [Qasim et al. 2026](https://www.nature.com/articles/s41598-026-74252-6) | Metadata-linked FAISS retrieval logs; ranking, similarity, Hit Rate@K and MRR; model/chunking comparisons | Stable evidence IDs, frozen queries, deterministic rankings, qrel coverage and accuracy of retrieved evidence | Our BM25 demonstration is *not* the article's FAISS implementation |
| [Li et al. 2026](https://doi.org/10.1093/jamia/ocag056) | Evaluates corpus structure, retrieval strategies and RAG architecture in sleep medicine | Predefined factorial ablations by source format, retriever and query type; no hidden holdout tuning | Domain-specific cohort; may not generalize |
| [MedRAG/MIRAGE, Xiong et al. 2024](https://aclanthology.org/2024.findings-acl.372/) | 7,663 questions across 5 medical QA datasets, comparing corpora, retrievers and backbone LLMs | Compare fixed corpus and question partitions across retrieval methods and baselines; report generator separately | Benchmarks are not prospective clinical trials |
| [MedCPT, Jin et al. 2023](https://pubmed.ncbi.nlm.nih.gov/37930897/) | Domain-specific contrastive retrieval from biomedical search logs | Implement ranking/qrels in independent fixtures before opt-in neural retrieval/reranking | Search logs and weights require separate permissions |
| [Masanneck et al. 2025](https://www.nature.com/articles/s41746-025-01536-y) | Assesses base versus evidence-augmented responses against neurology guidelines, including harmful responses | Require blinded harm ratings, abstention, contradiction and non-retrieval baseline tests | Retrieval gains did not eliminate unsafe answers |
| [Bareja et al. 2026](https://www.nature.com/articles/s41467-026-76004-6) | Compares 32 models over 41 pathology tasks including development and independent external sources | Keep slide/patient/site groups disjoint, report external performance and paired uncertainty | Publisher article is CC BY-NC-ND; paper, code, weights and datasets have different rights |
| [Rosenblatt et al. 2026](https://www.nature.com/articles/s41592-026-03115-9) | Perspective advocates truly independent validation against distribution shifts | Separate internal CV from external dataset evaluation; confirm no train-set harmonization leakage | Figure examples, not a reproduced neuroimaging training pipeline |
| [STARD-AI 2025](https://www.nature.com/articles/s41591-025-03953-8) | Reporting checklist for AI diagnostic accuracy studies | Map reference-standard, enrollment, test threshold and cohort flow to report | Not applicable automatically to all RAG benchmarks |

## Release classification

- **G0 — bibliographic identity:** Verified at publisher or official index for 28/28 DOI records; details should be rechecked when sources revise.
- **G1 — code links:** 13/13 GitHub repository URLs resolve; corresponding release commits, licenses, model-weight licenses and dependencies **pending**.
- **G2 — internal synthetic baseline:** Original, self-contained BM25 implementation and positive/negative tests added to this PR; CI acceptance remains the gate.
- **G3 — paper-specific reproduction:** NOT EXECUTED for all 27; do not claim paper implementation equivalence.
- **G4 — clinical/data/privacy review:** BLOCKED; no patient-level or restricted research data used.
